# 通信の記録

この記録は非公式で無保証です。詳細は [README の免責事項](../../README.md#免責事項) を参照してください。

公式ツールにロガーを読み込ませて、`0xFF00` の通信を記録します。ログは `local/logs/` に作成します。

## 注意事項

- ロガーは公式ツールのプロセス内で動きます。記録に使うのは、内容を確認した手順だけにしてください
- 公式ツールは起動しただけで実機と通信します。接続したまま起動すると、操作しなくても通信が発生します
- QMK の動作中は実行しないでください
- 記録中は公式ツールを強制終了しないでください
- 安全弁で公式ツールが中止したときは、USB を抜き差しして、キー入力できることを確認してください

## 情報の取り扱い

- 純正 HFB、通信ログ、`.hks` は `local/` に置き、コミットや共有をしないでください
- 通信ログと公式ツールのログ（`~/Library/Application Support/hhkb-keymap-tool/`）にはシリアル番号が含まれる場合があります。内容を貼り付けて共有しないでください
- 公開する前に、ファームウェアのバイト列や個体情報が含まれていないことを確認してください

## 手順

コマンドはリポジトリのルートで実行します。

```sh
cargo build -p hid-logger
./scripts/run-official-tool.sh probe
./scripts/run-official-tool.sh read 2
```

`2` はレポート内のコマンドの位置です。モードによって、実機へ通すレポートが変わります。通さないレポートを送ろうとすると、公式ツールを終了コード 134 で中止します。

| モード | 実機へ通すレポート |
|---|---|
| `probe` | なし |
| `read` | 読み出しのコマンド |
| `keymap-write` | 読み出しとキーマップの書き込みのコマンド |
| `firmware-update` | `0xFF00` へのレポートすべて |

手元の記録では、公式ツールで `.hks` を保存すると、続けて書き込みのコマンド `86` を送ろうとしました。`read` では中止され、`keymap-write` では実機に書き込まれる可能性があります。詳しくは[解析記録](findings.md#hks-の保存と同時に書き込みが送られる)にあります。
