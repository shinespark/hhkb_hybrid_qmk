# Spec Delta

## Purpose

固定した参考実装、QMK 本体、ビルド環境から QMK を再現可能にビルドし、成果物が期待する値と一致することを確かめられるようにする。

## ADDED Requirements

### Requirement: 固定した入力だけでビルドする
CLI は、固定したコミットの参考実装と QMK 本体、ダイジェストで固定したビルド環境だけでビルドしなければならない（SHALL）。入力のコミットが固定した値と異なるか、未コミットの変更があるときは、ビルドしてはならない（MUST NOT）。

#### Scenario: 参照先のコミットが異なる
- **WHEN** 参考実装または QMK 本体のコミットが固定した値と異なる
- **THEN** 理由を表示し、ビルドせずに 0 以外で終了する

#### Scenario: 参照先に未コミットの変更がある
- **WHEN** 参考実装のキーボード定義に未コミットの変更がある
- **THEN** 理由を表示し、ビルドせずに 0 以外で終了する

### Requirement: 許可した構成だけをビルドする
CLI は、`default` と `via` の keymap だけをビルドできなければならない（SHALL）。ビルドのオプションを引数から渡す手段を持ってはならない（MUST NOT）。

#### Scenario: 許可していない keymap
- **WHEN** `default` と `via` 以外の keymap を指定する
- **THEN** ビルドせずに 0 以外で終了する

### Requirement: 成果物を期待する値と照合する
CLI は、ビルドした `.bin` の SHA-256 を、keymap ごとの期待する値と照合し、結果を表示しなければならない（SHALL）。

#### Scenario: 値が一致する
- **WHEN** ビルドした `.bin` の SHA-256 が期待する値と一致する
- **THEN** 一致したことと成果物のパスを表示し、0 で終了する

#### Scenario: 値が一致しない
- **WHEN** ビルドした `.bin` の SHA-256 が期待する値と異なる
- **THEN** 2 つの値を表示し、0 以外で終了する

### Requirement: 成果物をリポジトリに含めない
CLI は、ビルドの成果物を Git の管理外の `local/` に出力しなければならない（SHALL）。

#### Scenario: 出力先の確認
- **WHEN** ビルドが完了する
- **THEN** 成果物は `local/` にあり、`git status` に現れない

### Requirement: 実機に触れない
ビルドの CLI は、HID デバイスを開いてはならない（MUST NOT）。

#### Scenario: 実機を接続したままビルドする
- **WHEN** 実機を接続した状態でビルドする
- **THEN** 実機にレポートは送信されない
