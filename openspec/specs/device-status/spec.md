# device-status Specification

## Purpose

macOS から接続中の実機を取り違えずに識別し、書き込み系の操作を一切行わずに状態を読み取る。

## Requirements

### Requirement: USB 接続の実機だけを対象にする
CLI は、VID `04fe`、PID `0021` で、トランスポートが USB のデバイスだけを対象にしなければならない（SHALL）。

#### Scenario: Bluetooth でも接続されている
- **WHEN** 同じ ID のデバイスが USB と Bluetooth の両方で見えている
- **THEN** USB のデバイスだけが対象になる

### Requirement: 対象が 1 台のときだけ通信する
CLI は、Usage Page `0xFF00` のインターフェースの数を台数とし、ちょうど 1 台でない場合は何も送信してはならない（MUST NOT）。

#### Scenario: 対象が見つからない
- **WHEN** USB で接続された対象がない
- **THEN** 接続を確認するよう表示し、終了コードは 0 以外になる

#### Scenario: 複数台の接続
- **WHEN** USB で接続された対象が 2 台以上ある
- **THEN** 何も送信せず、1 台にするよう表示し、終了コードは 0 以外になる

#### Scenario: 1 台が複数のインターフェースを持つ
- **WHEN** 1 台のキーボードが 3 つのインターフェースとして見えている
- **THEN** 1 台として扱う

### Requirement: 送信せずに一覧を表示する
CLI は、デバイスを開かず、レポートを送信せずに、製品名・バージョン・HID インターフェースの Usage Page と Usage を表示できなければならない（SHALL）。

#### Scenario: 一覧の表示
- **WHEN** 一覧表示を実行する
- **THEN** インターフェースごとの情報が表示され、レポートは 1 つも送信されない

### Requirement: 開くインターフェースを限定する
CLI は、Usage Page `0xFF00` のインターフェースだけを非排他で開かなければならない（SHALL）。`0x01` と `0x0C` のインターフェースを開いてはならない（MUST NOT）。

#### Scenario: 状態確認中のキー入力
- **WHEN** 状態確認を実行する
- **THEN** 実行中もキー入力は妨げられない

### Requirement: 公式ツールと同時に通信しない
CLI は、公式ツールの実行中はデバイスを開いてはならない（MUST NOT）。

#### Scenario: 公式ツールの実行中
- **WHEN** 公式ツールの実行中に状態確認を実行する
- **THEN** デバイスを開かずにエラーを表示し、終了コードは 0 以外になる

### Requirement: 固定のレポートだけを送信する
状態確認では、CLI は、記録と完全に一致し、ユーザーが承認した固定のレポートだけを送信しなければならない（SHALL）。引数からレポートを組み立ててはならない（MUST NOT）。

#### Scenario: 承認済みのレポートがない
- **WHEN** 承認済みのレポートがない状態で状態確認を実行する
- **THEN** 一覧の情報だけを表示し、レポートは送信されない

### Requirement: 任意のレポートを送る手段を公開しない
CLI とライブラリの公開 API は、任意のバイト列を送信する手段を持ってはならない（MUST NOT）。

#### Scenario: 公開 API の確認
- **WHEN** 公開 API と CLI のオプションを確認する
- **THEN** バイト列を受け取って送信するものが存在しない

### Requirement: 判別できない状態を断定しない
CLI は、観測で区別できない状態を断定して表示してはならない（MUST NOT）。

#### Scenario: 純正と更新モードを区別できない
- **WHEN** 表示内容や応答から純正 FW と更新モードを区別できない
- **THEN** どちらかであることを示し、キー入力の可否で確認するよう案内する

### Requirement: 応答がないときは再送しない
CLI は、応答が制限時間内に届かない場合、再送せずに終了しなければならない（SHALL）。

#### Scenario: タイムアウト
- **WHEN** 送信したコマンドへの応答が制限時間内に届かない
- **THEN** タイムアウトを表示し、再送せず、終了コードは 0 以外になる
