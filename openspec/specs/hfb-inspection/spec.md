# hfb-inspection Specification

## Purpose

公式の更新ファイル（HFB）の構造と整合性を読み取り専用で確認し、後続の変更で安全に HFB を扱うための根拠を得る。

## Requirements

### Requirement: 構造の表示
CLI は、指定された HFB について、ファイルサイズと、解析で確認できたヘッダ・領域の情報を表示しなければならない（SHALL）。

#### Scenario: 公式 HFB の解析
- **WHEN** 公式 HFB を指定して解析を実行する
- **THEN** 確認できた各領域のオフセットとサイズが表示される

### Requirement: 整合性の検査
CLI は、計算方法を確認できた CRC ごとに、対象範囲と、再計算した値とファイル内の値の比較結果を表示しなければならない（SHALL）。

#### Scenario: 一致
- **WHEN** 改変されていない公式 HFB を検査する
- **THEN** 各 CRC の一致が表示され、終了コードは 0 になる

#### Scenario: 不一致
- **WHEN** CRC の対象範囲を 1 バイト改変した HFB を検査する
- **THEN** 不一致の CRC が表示され、終了コードは 0 以外になる

### Requirement: 機種と版の確認
CLI は、ファイルから確認できた機種と版を表示しなければならない（SHALL）。確認できない場合は結果を「未確定」としなければならない（SHALL）。

#### Scenario: 機種と版を確認できない
- **WHEN** 機種または版を読み取れない HFB を検査する
- **THEN** 「未確定」と表示し、終了コードは 0 以外になる

### Requirement: 不正な入力の拒否
CLI は、想定する構造に一致しないファイルを、推測で解釈せずエラーにしなければならない（SHALL）。

#### Scenario: 短すぎるファイル
- **WHEN** ヘッダより短いファイルを指定する
- **THEN** 理由を示すエラーを表示し、終了コードは 0 以外になる

### Requirement: 読み取り専用
解析は入力ファイルを変更してはならず（MUST NOT）、実機と通信してはならない（MUST NOT）。

#### Scenario: 解析の前後
- **WHEN** 解析を実行する
- **THEN** 入力ファイルのハッシュは実行の前後で変わらない
