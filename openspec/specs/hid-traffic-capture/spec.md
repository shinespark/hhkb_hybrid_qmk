# hid-traffic-capture Specification

## Purpose

公式ツールと実機の HID 通信を macOS 上で記録し、プロトコルを自前で解析するための一次データを、意図しない送信を防ぎながら得る。

## Requirements

### Requirement: 通信の記録
ロガーは、各レポートについて通し番号、時刻、方向、レポート種別、レポート ID、長さ、戻り値、デバイスの識別情報（Transport、Usage Page、LocationID）を記録しなければならない（SHALL）。

#### Scenario: 送信の記録
- **WHEN** 公式ツールがレポートを送信する
- **THEN** 送信方向のエントリと戻り値がログに追記される

#### Scenario: 受信の記録
- **WHEN** 公式ツールが入力レポートを受け取る
- **THEN** 受信方向のエントリがログに追記される

#### Scenario: 記録の欠落
- **WHEN** ログの書き込みに失敗する
- **THEN** 通信は妨げず、欠落を通し番号で検出できる

### Requirement: 全バイトの記録は更新用インターフェースに限る
ロガーは、Usage Page `0xFF00` のレポートだけ全バイトを記録し、他のインターフェースの内容を記録してはならない（MUST NOT）。

#### Scenario: キーボード入力
- **WHEN** Usage Page `0x01` の入力レポートを受け取る
- **THEN** メタデータだけが記録され、打鍵内容は記録されない

### Requirement: 許可されたレポートは変更しない
ロガーは、許可されたレポートの内容・順序・戻り値を変更してはならず（MUST NOT）、独自のレポートを送信してはならない（MUST NOT）。

#### Scenario: 透過
- **WHEN** 許可されたレポートを記録する
- **THEN** 公式ツールと実機の間では同じ内容が同じ順序で受け渡され、公式ツールには元の戻り値が返る

### Requirement: 許可のない送信を止める
ロガーは、指定されたモードで許可されていない送信を検出したとき、送信せずに記録してプロセスを中止しなければならない（SHALL）。送信成功を偽装してはならない（MUST NOT）。

#### Scenario: 読み出しモードでの書き込み
- **WHEN** 読み出しモードで許可リストにないコマンドが送信されようとする
- **THEN** そのレポートは実機に届かず、内容がログに残り、プロセスが中止される

#### Scenario: コマンドの位置が未確定
- **WHEN** コマンドの位置を確定する前のモードで最初のレポートが送信されようとする
- **THEN** そのレポートは実機に届かず、内容がログに残り、プロセスが中止される

### Requirement: 公式ツールのファイルを変更しない
記録にあたって、公式ツールのバイナリと署名を変更してはならない（MUST NOT）。

#### Scenario: 記録前後の検証
- **WHEN** 記録の前後で公式ツールの署名を検証する
- **THEN** どちらも検証に成功する

### Requirement: ログの保存先と権限
ロガーは環境変数で指定された場所に、所有者だけが読み書きできる権限でログを保存しなければならない（SHALL）。指定がなければ何も記録してはならない（MUST NOT）。

#### Scenario: 保存先の指定なし
- **WHEN** 保存先の環境変数を指定せずに起動する
- **THEN** ログは作成されず、すべての送信が止められる

#### Scenario: `local/` への保存
- **WHEN** 保存先に `local/` 配下を指定して記録する
- **THEN** ログの権限は 0600 になり、`git status` に現れない
